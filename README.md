# SaaS Analytics 

##📌 Project Overview

This project analyzes SaaS customer, subscription, revenue, usage, payment, churn, and support ticket data to identify key business trends and performance insights.

The project combines SQL, Python, and Power BI to perform data validation, analysis, visualization, and business reporting.

##🎯 Project Objectives

- Analyze customer and subscription trends
- Monitor revenue and payment performance
- Understand customer churn patterns
- Analyze product usage behavior
- Track support ticket performance
- Build interactive Power BI dashboards
- Generate business insights from SaaS data

##🛠️ Tools & Technologies

- Python – Data generation and data processing
- MySQL – Data storage, cleaning, validation, and SQL analysis
- Power BI – Interactive dashboards and visualization
- Pandas & NumPy – Data processing and analysis
- GitHub – Project version control and portfolio presentation

##📈 Power BI Dashboard

The Power BI dashboard contains multiple analytical pages:

###Executive Dashboard

Provides an overall view of customers, subscriptions, and business performance.

###Revenue Dashboard

Analyzes revenue, payment performance, plans, and financial trends.

###Customer Dashboard

Analyzes customer types, churn, auto-renewal, and customer revenue.

###Usage Dashboard

Analyzes product usage, active devices, logins, storage, and usage behavior.

###Customer Details

Provides detailed customer-level analysis using drill-through functionality.
